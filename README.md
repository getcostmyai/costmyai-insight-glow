# CostMyAI rebuilt

Attached find the user dashboard for CostMyAI. This is the actual status. The data is correct, everything we need to show our clients is there. Just the design needs an overwork: it looks boring, it is hard to figure out in 1-2 second which of the information are important, it needs eye catching graphics and clarity for the user. We would like to have it in an apple like style and mood. The corporate colors and fonts need to stay. The colors of numbers and KPIs you’re allowed to change according to the subject they show. Do not work with serif like fonts anywhere, especially not in numbers.



I want you to change what you think is best for the dashboard, what is best in clarity for the client, best in marketing for us, and a couple of very fancy/sexy visuals-like diagrams would be nice. Order of information, way of leading through the entire dashboard is all yours.
